## 卡片游戏

- **定义**：以 PluginCard（iframe 卡片）形式嵌入在对话流中的前端交互游戏
- **别名**：card、小游戏
- **相关模块**：`routes/game.js`（统一入口，`?game=` 分发）

## 游戏模块

- **定义**：每个游戏类型的独立 JS 模块，处理渲染、交互逻辑、计分规则和数据收集。放在 `assets/games/{游戏名}/game.js`
- **别名**：game module
- **相关模块**：`assets/games/schulte/game.js`、`assets/games/stroop/game.js` 等

## 舒尔特表格

- **定义**：数字网格游戏，随机排列，用户按升序点击，计时完成。MVP 游戏，也是后续游戏模块的模板参考
- **难度系统**：模式（标准/记忆）× 规模（5×5, 6×6, 7×7）二维调节，6 种组合独立统计，key 格式 `schulte_{standard|memory}_{5|6|7}`
- **别名**：数字网格、舒尔特、Schulte Grid
- **相关模块**：`assets/games/schulte/game.js`

## Stroop 色词测试

- **定义**：色词干扰抑制游戏，判断字体颜色（忽略词义），按 1-4 键选择颜色。50% 一致/50% 不一致产生语义-颜色冲突。标准模式测基础干扰抑制，高干扰模式（25:75 比例）增加认知负荷。主指标为 Stroop 效应量（不一致 RT − 一致 RT），越小越好
- **难度系统**：模式（标准/高干扰）× 规模（30/50/70 试次）二维调节，6 种组合独立统计，key 格式 `stroop_{standard|enhanced}_{30|50|70}`
- **别名**：色词、Stroop
- **相关模块**：`assets/games/stroop/game.js`

## 表现模块

- **定义**：游戏结束后展示用户本轮数据的卡片区域。结构：分数大字 + 等级评价 + 对比旁注 + 趋势曲线（Schulte≥5 次，Go/No-Go≥3 次）
- **相关模块**：`assets/games/shared/results.js`（渲染引擎）、`assets/games/shared/evaluations.js`（评价数据）
- **状态**：已归档，未来版本恢复

## 游戏对比

- **定义**：将本轮表现（用时、准确率）与上次同游戏数据做差值比较，输出文字 + 图标反馈
- **别名**：对比、PK上次
- **相关模块**：卡片内嵌 JS + localStorage 历史数据

## 趋势曲线

- **定义**：同一游戏累计多次记录后，用折线图展示成绩趋势。Schulte 需≥5 次、Go/No-Go≥3 次。标注单点：最好成绩在对应数据点下方
- **别名**：曲线图、进度图
- **相关模块**：卡片内嵌 JS（Canvas 或 SVG 简单绘图）

## 评价系统

- **定义**：根据用时/准确率复合分对每次游戏给出 S/A/B/C/D 五级评价，附带一句随机个性化点评
- **架构决策**：评价数据（阈值表+词库+显示标签）放在 `shared/evaluations.js` 按游戏组织。`shared/results.js` 提供通用 `evaluate()` / `pickComment()` 函数，但 modeKey→标签映射在 `results.js` 的 `showResults()` 中硬编码——添加新游戏需在 `evaluations.js` 追加阈值和点评数据，同时在 `results.js` 的 labels 映射中加条目
- **相关模块**：`assets/games/shared/evaluations.js`（数据）、`assets/games/shared/results.js`（引擎+标签）

## 设计规范

- **定义**：从舒尔特表格开发中抽取的游戏设计模板，含配色系统、布局结构、交互反馈规范、难度梯度、数据存储等 8 章
- **维护原则**：规范是模板而非需求，后续游戏以它为参考实现，新发现的原则追加到文件，新需求写入 CONTEXT.md
- **别名**：DESIGN.md
- **相关模块**：`DESIGN.md`

## 难度梯度

- **定义**：每个游戏支持的模式×规模二维难度调节。模式区分认知负荷（标准/记忆），规模区分信息密度（5/6/7）。每种组合独立统计，key 格式 `{game}_{mode}_{size}`
- **别名**：难度、难度设置
- **相关模块**：`config.json`（难度配置）、游戏内联 JS（难度切换 UI）

## 交互反馈

- **定义**：用户操作后的即时视觉反馈规范。正确点击 0.22s 暖金覆层，错误点击 0.25s 暖玫覆层，完成 0.8s 淡出。所有反馈仅用半透明覆层不重绘文字，避免重影
- **相关模块**：游戏内联 JS（`flashCellPress`、`flashError`）

## 游戏白名单

- **定义**：由 `config.json` 中 `games` 对象的 `implemented` 字段控制。已实现的游戏正常出卡，未实现的返回「尚未就绪」提示。`start-game.js` 和 `routes/game.js` 均从 config 动态读取白名单
- **别名**：游戏注册表
- **相关模块**：`config.json`

## token 注入

- **定义**：iframe 鉴权机制。`game-page.js` 渲染 HTML 时将 token 注入为 URL query 参数和 JavaScript 模板变量，外部 `<script src>` 也附带 `?token=` 参数。游戏模块通过 `postMessage` 事件监听器闭包间接使用（`submitResult` 已捕获注入值），无需直接访问
- **相关模块**：`routes/game-page.js`
